# Student Exam Performance Prediction

## Project Overview

This project predicts a student's math score based on their demographic information and reading and writing scores.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Flask
- Git & GitHub

## Machine Learning Workflow

1. Data Ingestion
2. Data Transformation
3. Model Training
4. Hyperparameter Tuning
5. Prediction Pipeline
6. Flask Web Application

## Features

The application takes the following inputs:

- Gender
- Race/Ethnicity
- Parental Level of Education
- Lunch
- Test Preparation Course
- Reading Score
- Writing Score

It then predicts the student's math score.
